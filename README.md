# YOLO Manager

**バージョン**: 2.1.0

YOLO Manager は、AI（YOLOv8 / YOLOv11）を使った画像検知システムの構築を、専門知識がなくてもスムーズに行えるようにサポートするためのツールです。

データの準備から、自動アノテーション、学習、推論テスト、そしてラズパイ等の小型デバイスで高速に動作するモデル（NCNN）への変換までを、一貫したワークフローで行えます。

---

## 主な機能とワークフロー

本アプリは、以下の 6 つのステップに沿って操作することで、独自の AI モデルを作成できます。

### 1. データセット準備
大量の画像の中から、AI の「練習用」と「テスト用」に使う画像を自動で選別・コピーし、必要なフォルダ構造を瞬時に作成します。

### 2. ラベル設定
AI に覚えさせたい物体の名前（クラス名）を登録します。

### 3. 自動アノテーション (対応モデルがある場合)
既存の学習済みモデル（.pt）を使って、新しい画像に対して自動でラベル（下書き）を付けます。手作業の時間を大幅に短縮でき、結果は Excel で一覧確認可能です。

### 4. 手動アノテーション
定番ツール `labelImg` をワンクリックで起動します。自動アノテーション結果の修正や、新規のラベル付けを効率的に行えます。※Python 3.10以降の最新環境にも対応済み。

### 5. 学習実行
YOLOv8 に加え、最新の **YOLOv11** にも対応。複雑なコマンド入力なしで、最適なパラメータでの学習を開始できます。学習完了時には、ラズパイ等の小型デバイスで高速動作する「NCNN」形式のモデルも自動生成されます。

### 6. 推論 (日本語Excel出力付き)
完成したモデルを使って判定テストを行います。検知結果（信頼度や個数）を日本語ヘッダーの Excel に出力し、画像は検知個数ごとに自動で仕分け保存されます。

---

## その他の特徴
- **見やすく使いやすいUI**: 文字サイズやボタンを大きく設計し、読みやすさと操作性を重視しています。
- **充実の日本語ヘルプ**: 初心者でも迷わないよう、5つの目的別操作パターン（初回作成、精度向上、デバイス変換など）を詳しく解説しています。
- **設定項目のGUI設定/日本語化**: 「学習回数(Epochs)」「バッチサイズ(Batch)」などをGUI画面より設定でき、専門用語をわかりやすく日本語表記しています。
- **パッケージ一括確認**: 必要なライブラリの不足をボタン一つでチェック・自動インストールできます。
