# YOLOマネージャー (YOLO Manager)

**バージョン**: 2.6.0

YOLO Manager は、AI（YOLOv8 / YOLO11 / **YOLO26**）を使った物体検出・画像検知システムの構築を、プログラミングや専門知識がなくてもスムーズに行えるように設計されたデスクトップGUIツールです。

データセットの自動準備、自動/手動アノテーション、モデル学習、微小物体を高精度に検出する **SAHI (Slicing Aided Hyper Inference)** 対応のタイル分割学習・推論、クラス別信頼度ヒストグラム＆統計情報の自動生成、Excelレポート出力、そして Raspberry Pi などの小型デバイスで高速動作する軽量モデル（NCNN形式）の自動生成までを、一貫したワークフローで行うことができます。

---

## 🌟 主な特徴

- **推論・自動アノテーション時の信頼度ヒストグラム＆統計表 自動生成**
  - 推論実行時および自動アノテーション完了時に、検出されたオブジェクトのクラス別信頼度ヒストグラム画像を自動生成。
  - 各クラスごとに**左側に統計表（N, 平均, 中央値, MAX, MIN, 標準偏差）**、**右側に信頼度ヒストグラム**を横並びで配置。1行あたり最大4列まで整列し、超過時は自動で次行へ折り返す見やすいグリッドレイアウトを採用。
- **ラベル一覧確認画面の絞り込みフィルター**
  - ステップ4.3「ラベル一覧確認」画面に、データ種別（すべて/train/val）、アノテーション有無（すべて/あり/なし）、キーワード検索（画像名・クラス名）によるリアルタイム絞り込みフィルターを追加。
  - 画面上では絞り込みを行いつつ、Excelファイル出力は全件を出力可能。
- **画像枚数不足時の自動比率コピー**
  - 画像コピー時に元画像の枚数が指定された枚数より少ない場合でもエラー終了せず、ある分だけ設定された比率（train : val）を維持して自動分割コピー。
- **最新 YOLO モデル対応 (デフォルト: YOLO26n) & ultralytics アップデート支援**
  - 最新の **YOLO26**、**YOLO11**、および安定の YOLOv8 に標準対応。初期値として最も軽量・高速な **YOLO26n** を設定済み。
  - 設定画面の「パッケージ確認」にて、ultralytics の最新バージョンへのアップグレード確認を追加。
  - ultralytics のバージョンが古く YOLO26 が動作しない場合、ログに最新化を促すわかりやすいガイドを出力。
- **推論時の重なり判定閾値 (IoU) スライダー**
  - 設定画面から「信頼度閾値 (Conf)」に加え、「重なり判定閾値 (IoU)」をスライダーで直感的に調整可能（0.01〜1.00、初期値: 0.70）。
  - 通常推論の NMS 処理、および SAHI スライス推論のスライス結合時の重複除去にリアルタイム反映されます。
- **SAHI / タイル分割機能（高解像度・極小物体対応）**
  - **タイル分割学習**: 高解像度画像をタイル状にスライスした一時データセット（`train_sliced/`, `val_sliced/`）を自動生成して学習。元データは一切改変せず、学習後に自動削除されます（背景サンプリング率: 50%）。
  - **SAHI スライス推論**: ステップ6「推論」およびステップ3「自動アノテーション」で画像を小タイルに分割して検知・結合。広角カメラや高解像度画像内の小さな部品・物体も見逃さずに高精度検出します。
  - **YOLO統一描画**: SAHI 推論時も YOLO 標準の `Annotator` を採用し、クラスごとの鮮やかな色分け（`colors`）や、元画像解像度に応じたフォントサイズ・線幅の自動スケーリング描画を実現。
- **classes.txt 自動読込**
  - 設定画面で「データセット保存先」を指定した際、フォルダ直下に `classes.txt` があれば自動的にクラス名として読み込み（確認ダイアログ不要）。
- **マルチプラットフォーム & Raspberry Pi セーフティ**
  - 設定画面からデスクトップ起動用ファイル（Windows: `YOLOマネージャー.bat` / Linux・ラズパイ: `YOLOマネージャー.sh`）をワンクリックで自動作成可能。
  - Raspberry Pi OS（Bookworm 等）の Wayland 環境に対応し、Qt プラットフォーム（Xwayland/xcb）で安定起動。
  - システム Python（`/usr/bin/python` 等の非仮想環境）指定時でも、`--break-system-packages` と `--user` を自動適用し、PEP 668 制約下でも安全に必要パッケージをインストール可能。
  - Raspberry Pi 環境を自動検出し、過負荷や発熱防止のため「5. 学習実行」ボタンを自動的に無効化（推論やラベル確認等に専念可能）。
- **安全なファイルオープン & Excel ビューア自動判定**
  - Windows では `os.startfile`、Linux/ラズパイでは `xdg-open` を安全に呼び出す `safe_open_path` を搭載。
  - Excel ファイル（`.xlsx`）を開くアプリ（LibreOffice 等）が存在しない環境では、クラッシュを完全に防ぎ自動オープンを安全にスキップ（ファイル作成・保存のみ行い、ログにオープン中止の旨を記録）。
- **堅牢な自動エラーリカバリ & データ整合性**
  - **CUDA OOM (VRAM不足) 自動復旧**: 学習時に GPU メモリ不足が発生した場合、自動的に VRAM を解放し、安全なバッチサイズで自動リトライ。
  - **未アノテーション画像の空ラベル自動補填**: ラベルが付いていない画像に空の `.txt` を自動生成し、背景サンプル（ネガティブサンプル）として YOLO に正常認識させます。
- **直感的な日本語GUI & ヘルプ**
  - 初心者でも迷わない目的別ガイド（初回作成、既存データセット利用、精度向上、推論テスト、SAHI微小物体検知、ラズパイ運用）をヘルプ画面に完備。
  - オーギュメント設定や SAHI 設定は、画面をスッキリ保てる「折りたたみグループ」に格納。

## 📋 ワークフロー（6つのステップ）

アプリ画面左側のステップに沿って進めるだけで、独自の検知モデルが完成します。

```
[1. データセット準備] ➔ [2. クラス名設定] ➔ [3. 自動アノテーション] (任意)
                                                    ↓
[6. 推論 (Excel出力)] ← [5. 学習実行] ← [4. 手動アノテーション (labelImg)]
```

### 1. データセット準備
元画像フォルダから画像を取り込み、AIの学習用（`train`）と検証用（`val`）に自動分割してフォルダを作成・コピーします。コピー中はリアルタイムに進捗が表示されます。

### 2. クラス名設定
検知対象のクラス名（ラベル名）を1行1つで入力・登録します。データセット直下に `classes.txt` が存在する場合は自動で読み込まれます。

### 3. 自動アノテーション (対応モデルがある場合)
既存の学習済みモデル（`.pt`）を使って、新しい画像に対して自動で下書きラベルを付与します。SAHI推論をONにすれば微小物体も自動検出できます。検出結果は `autolabel_result.xlsx` に出力されます。

### 4. 手動アノテーション
内蔵の日本語化済み `labelImg` をワンクリックで起動し、ラベル付けの確認や修正を行います。
- **4.1 学習用**: `train` フォルダのアノテーション
- **4.2 検証用**: `val` フォルダのアノテーション
- **4.3 ラベル一覧**: アノテーション状況を `ラベル一覧.xlsx` に自動出力して確認可能

### 5. 学習実行
YOLO26 / YOLO11 / YOLOv8 のモデル学習を開始します。
- 未アノテーション画像には空ラベルが自動補填されます。
- 「SAHI / タイル分割設定」が有効な場合は、画像をタイル状にスライスした一時データセットで学習を実行します。
- 学習完了時、ラズパイ向けの超軽量モデル（**NCNN形式**）も自動生成されます。
*(※Raspberry Pi 環境上では安全のため本ボタンは無効化されます)*

### 6. 推論 (日本語Excel出力付き)
完成したモデルを使ってテスト画像を判定します。
- **SAHI スライス推論**: 設定により、高解像度画像内の極小物体も高精度に検出可能。
- **自動仕分け**: 検出個数ごとにフォルダ（`結果画像/0/`, `結果画像/1/` 等）へ自動整理・保存。
- **Excelレポート**: ファイル名、検出クラス、信頼度、個数をまとめた Excel を自動出力します。

## 🛠️ 動作要件

- **OS**: Windows 10/11, Linux, Raspberry Pi OS (Raspbian / 64-bit推奨)
- **Python**: Python 3.10 以上
- **GPU**: NVIDIA GPU (CUDA対応、学習実行時に推奨) ※推論のみであればCPU/ラズパイでも動作可能

### 主な依存パッケージ
- `ultralytics` (YOLO)
- `sahi` (スライス推論)
- `PyQt6` (GUI)
- `labelImg` (アノテーションツール、Python 3.10+ パッチ適用済)
- `pandas`, `openpyxl` (Excel入出力)
- `Pillow`, `opencv-python` (画像処理)
- `PyYAML`

## 🚀 起動方法

### Windows
プロジェクト直下の `yolo_manager.bat` をダブルクリック、または設定画面から「ショートカット作成」を押してデスクトップに生成されたアイコンから起動できます。

```bat
cd yolo_app
python main.py
```

### Linux / Raspberry Pi
設定画面で生成した `YOLOマネージャー.sh`、またはターミナルから以下を実行します。

```bash
cd yolo_app
python3 main.py
```
